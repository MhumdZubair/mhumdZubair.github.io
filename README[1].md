# Muhammad Zubair Portfolio

Static portfolio website ready for free hosting.

## Publish free with GitHub Pages
1. Create a GitHub account at https://github.com/
2. Create a new public repository named `muhammadzubair.github.io` (or any repository if using a project URL).
3. Upload `index.html`.
4. Open Settings → Pages.
5. Select the main branch and root folder, then save.
6. GitHub will provide your free HTTPS portfolio URL.

Before publishing, replace `YOUR_EMAIL@example.com` in `index.html` with your real email and update the LinkedIn link.
